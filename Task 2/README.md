## Objective
Clean a dataset by handling missing values and improving overall data quality using Python, Pandas, and NumPy.

## Dataset
House Prices Dataset used

## Steps Performed
- Loaded the dataset
- Checked missing values using `.isnull().sum()`
- Visualized missing data with bar charts
- Filled numerical missing values with mean/median
- Filled categorical missing values with mode
- Removed columns with high missing values
- Validated cleaned dataset
- Compared before/after cleaning

## Outcome
Mastered data cleaning techniques and missing value handling strategies.
